# 0.3.9 — 2026-10-18

## Added

- **Specimen metadata** exposes reported scientific names, taxonomy ranks, and valid decimal collection coordinates; search accepts exact `filters.scientific_name` values ([#56](https://github.com/cyanheads/smithsonian-mcp-server/issues/56)).
- **`filters.online_media_type`** accepts exact indexed media categories with vocabulary-aware recovery; category membership does not guarantee downloadable images ([#57](https://github.com/cyanheads/smithsonian-mcp-server/issues/57)).

## Fixed

- **Filtered searches** preserve implicit multi-word matching while grouping active Lucene expressions for Boolean precedence ([#53](https://github.com/cyanheads/smithsonian-mcp-server/issues/53)).
- **Object notes** retain labels and source order; `description` selects recognized prose instead of administrative notes ([#54](https://github.com/cyanheads/smithsonian-mcp-server/issues/54)).
- **Media titles** use the shared plain-text projection in success output and media errors ([#55](https://github.com/cyanheads/smithsonian-mcp-server/issues/55)).
- **Related searches** disclose failed signals alongside empty-result and paging guidance; all-failed searches and caller cancellation reject ([#58](https://github.com/cyanheads/smithsonian-mcp-server/issues/58)).
