# 0.3.6 — 2026-08-24

## Changed

- **Protocol compatibility** now covers MCP 2026-07-28 alongside 2025 clients.
- **Tool contracts** reject unknown top-level inputs, advertise `additionalProperties: false`, emit JSON Schema 2020-12, and declare the structured error envelope.
- **Request-scoped logs** can reach clients through MCP logging notifications, so messages passed to `ctx.log` are treated as client-visible.
- **HTTP sessions** are explicitly stateless across source, container, and documentation configuration.
- **Response telemetry** records output validation, formatting, and enrichment failures as failed calls rather than successful handler executions.
- **Container builds** use Bun 1.4.0, native build-platform execution, and omit unused optional peer tiers from production images.
- **Security reports** use `security@caseyjhand.com` as the published email contact.
