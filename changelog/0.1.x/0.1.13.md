# 0.1.13 — 2026-07-10

## Added

- **`smithsonian_find_related` `start` pagination** — optional `start` input (0-indexed, default 0) offsets the merged interleaved related-object sequence; each fan-out fetches from the top (`start: 0`) with `rows = min(start + limit, 100)`, so `start = page × limit` yields contiguous, gap-free pages. ([#18](https://github.com/cyanheads/smithsonian-mcp-server/issues/18))
- **`truncationCeiling` enrichment field** — the summed upstream match count across contributing fan-out signals, surfaced as an upper bound on the related pool; `truncated` now also fires when a signal reports more upstream matches than were fetched. ([#18](https://github.com/cyanheads/smithsonian-mcp-server/issues/18))

## Changed

- **Package/manifest descriptions** — reworded across `package.json`, `manifest.json`, `.claude-plugin/plugin.json`, and `.codex-plugin/plugin.json` to mention coverage across 20+ museums and STDIO/Streamable HTTP transport support.
- **`package.json`** — `repository.url` → `git+https://github.com/cyanheads/smithsonian-mcp-server.git`; `author` gains `(https://caseyjhand.com)`.
- **`manifest.json`** — adds `"license": "Apache-2.0"`; `author` → `cyanheads`.
- **`.github/FUNDING.yml`** — new, enables the GitHub Sponsors button (`github: cyanheads`) and links Buy Me a Coffee (`buy_me_a_coffee: cyanheads`).

## Fixed

- **`smithsonian_get_object` topic rendering** — `format()` no longer caps the Topics line at 10; every topic renders, restoring parity with `structuredContent.topics`. ([#17](https://github.com/cyanheads/smithsonian-mcp-server/issues/17))
- **`smithsonian_find_related` signal accumulation** — `similarity_signals` now accumulates every distinct signal that surfaced a related object across all fan-outs, instead of keeping only the first-discovering signal. ([#19](https://github.com/cyanheads/smithsonian-mcp-server/issues/19))
