# 0.1.12 — 2026-07-10

Combines four own-issue fixes with `@cyanheads/mcp-ts-core` 0.10.14 maintenance and Bun supply-chain hardening.

## Added

- **Recovery hints on every `ctx.fail()` site** — all 9 error-throw sites across `smithsonian_search`, `smithsonian_get_media`, `smithsonian_list_terms`, `smithsonian_get_object`, `smithsonian_find_related`, and `smithsonian_explore` now spread `ctx.recoveryFor(reason)` into the thrown `data`, so each contract's declared `recovery` text reaches the wire as `data.recovery.hint` (mirrored into `content[]`). ([#14](https://github.com/cyanheads/smithsonian-mcp-server/issues/14))
- **`smithsonian_search` filtered-zero term suggestions** — on `invalid_filter`, the handler re-runs the query once without filters and harvests up to 12 distinct `object_type` and `unit_code` values that co-occur with it, naming exact controlled-vocabulary terms to retry with; falls back to #14's static hint if the re-query is empty or throws. ([#15](https://github.com/cyanheads/smithsonian-mcp-server/issues/15))
- **`date` field on `smithsonian_search` summaries** — sparse decade value (e.g. `"1960s"`) sourced from `indexed.date[0]`, added to `ObjectSummary` and rendered in both `structuredContent` and `format()` text. ([#20](https://github.com/cyanheads/smithsonian-mcp-server/issues/20))
- **`bunfig.toml`** — blocks installing package versions published less than 3 days ago (`minimumReleaseAge`, with `@cyanheads/mcp-ts-core` excluded for same-day adoption) and enables `@socketsecurity/bun-security-scanner` for install-time malware/typosquat/CVE scanning.
- **`.github/SECURITY.md`** — vulnerability disclosure policy.
- **`.gitattributes`** — normalizes line endings to LF, marks binary asset types, and flags `bun.lock`/`CHANGELOG.md`/`docs/tree.md` as `linguist-generated`.

## Changed

- **Dockerfile** — base image pinned `oven/bun:1.3` → `oven/bun:1.3.14` (both stages); every `bun install` step mounts a BuildKit cache at `/root/.bun/install/cache`; the build stage now also runs `--ignore-scripts`.
- **`package.json`** — pins `packageManager: bun@1.3.14`; adds `trustedDependencies: ["@socketsecurity/bun-security-scanner"]` so its postinstall script is allowed to run under Bun's script-blocking default.
- **devcheck** outdated-dependency check no longer flags packages held back by `bunfig.toml`'s `minimumReleaseAge` guard (marked `*` by `bun outdated`) as drift.
- **Vendored `skills/`** (12 directories) **and `scripts/`** re-synced to the installed framework version.

## Fixed

- **`smithsonian_list_terms` past-end pagination** — the `no_terms` guard now fires only when `total === 0` instead of `terms.length === 0`; a page requested past the end of a non-empty vocabulary returns `{ field, terms: [], total }` as a successful empty page rather than throwing. ([#16](https://github.com/cyanheads/smithsonian-mcp-server/issues/16))
