# 0.1.15 — 2026-07-11

## Changed

- **`.codex-plugin/plugin.json` `longDescription`** — dropped "full provenance metadata" and "cross-collection fan-out" wording left over from 0.1.14's tool-description sweep; now matches the actual output contract (normalized object metadata, discovery across collections). ([#22](https://github.com/cyanheads/smithsonian-mcp-server/issues/22))

## Fixed

- **`smithsonian_find_related` deep pagination** — per-signal fetch depth raised from 100 to 5,000, fetched upstream in ≤1,000-row chunks (the EDAN API silently returns a 10-row page instead of erroring when `rows` exceeds 1,000). Pages past the old wall (e.g. `start: 300` across active signals) now return real, contiguous results instead of an empty page. `truncationCeiling` is capped at each signal's reachable depth before summing, so it never discloses more than `start` can actually retrieve. ([#18](https://github.com/cyanheads/smithsonian-mcp-server/issues/18))

## Dependencies

- `@types/node` `^26.1.0 → ^26.1.1`
- `@biomejs/biome` `^2.5.2 → ^2.5.3`
